# 앱 연동 요청: 공지, 문의, 닉네임, 채팅

아래 내용은 서버 PR 기준입니다. 머지와 배포가 완료된 뒤 해당 환경에서 연동해 주세요.

## 공지

- 로그인 없이 `GET /api/v1/notices?platform=IOS&page=0&size=20`으로 목록을 조회합니다. `tickerOnly=true`를 추가하면 티커 공지만 조회합니다.
- 상세는 `GET /api/v1/notices/{id}?platform=IOS`입니다. 응답의 `ticker`는 티커 표시 여부입니다. iOS 앱은 전체 공지와 iOS 공지를 함께 받도록 `platform=IOS`를 전달해 주세요.
- 목록은 `data.content`, `totalPages` 등 페이지 정보로 구성됩니다. 등록 직후가 아니라 관리자가 게시한 공지만 노출됩니다.

## 문의

- 로그인 사용자는 `POST /api/v1/inquiries`에 `{ "title": "제목", "content": "내용" }`을 보내 문의를 등록합니다. 제목은 최대 200자, 내용은 최대 10,000자입니다.
- 내역은 `GET /api/v1/inquiries?page=0&size=20`, 상세는 `GET /api/v1/inquiries/{id}`입니다. `status`는 `WAITING` 또는 `ANSWERED`이며 답변은 `answer`, `answeredAt`을 확인해 주세요.
- 사진은 문의 등록 후 `PUT /api/v1/inquiries/{id}/image`에 multipart 필드 `image`로 한 장을 올립니다. JPEG 또는 PNG, 최대 5 MiB입니다. 재업로드하면 해당 문의의 사진을 교체합니다. 문의 등록과 사진 업로드가 별도 요청이므로 사진 업로드 실패 시 문의가 이미 등록되었음을 표시하고 재시도할 수 있게 해 주세요.
- `hasImage`가 true이면 인증 헤더와 함께 `GET /api/v1/inquiries/{id}/image`를 요청해 이미지를 표시합니다. 이미지는 작성자와 관리자만 조회할 수 있으므로 인증 헤더를 전달할 수 있는 로더를 사용해 주세요.

## 닉네임

- 기존 `POST /api/v1/auth/register-nickname`의 닉네임은 공백을 제외한 유효한 입력으로 최대 8글자입니다. 서버는 이모지 조합을 포함한 사용자에게 보이는 글자 단위로 확인하며 내부 길이 상한도 적용합니다.
- 기존 60일 변경 제한과 중복 확인은 유지됩니다. 변경 성공 후 프로필과 캐시된 게시글·댓글 목록을 다시 불러오면 현재 닉네임을 확인할 수 있습니다.

## 채팅 사진 및 신고

- 사진을 전송할 때 `POST /api/v1/chat/images`에 multipart 필드 `image`를 보내고, 응답의 `imageKey`를 기존 STOMP 전송 메시지의 `{ "message": "내용", "imageKey": "발급받은 키" }`에 넣습니다. 전송 경로는 `/pub/matches/{matchId}/chat/messages`입니다. 텍스트와 사진 중 하나 이상이 필요합니다.
- 채팅 내역 `GET /api/v1/chat/{matchId}/history`의 이미지 URL을 표시합니다. 사진이 관리 조치된 경우 다시 조회한 내역에서 해당 채팅의 사진이 사라집니다. 사진만 있던 채팅은 내역에서 제외됩니다. 현재 별도의 삭제 실시간 이벤트는 없으므로 화면 재진입 또는 새로고침 시 내역을 갱신해 주세요.
- `POST /api/v1/chat/messages/{id}/reports`에 `{ "reason": "신고 사유" }`를 보냅니다. 사유는 필수이며 최대 500자이고, 같은 사용자의 중복 신고는 허용되지 않습니다.
- 관리자의 사진 삭제는 선택한 채팅에만 적용됩니다. 같은 원본을 참조하는 다른 채팅이나 게시글은 유지됩니다.

## 계정 상태와 미구현 항목

- 관리자 조치로 계정이 정지되거나 영구탈퇴되면 기존 인증이 더 이상 유효하지 않을 수 있습니다. API 인증 실패 시 기존 로그인 만료 처리와 서버 오류 메시지를 사용해 주세요.
- 사용자 알림 목록·알림 설정 API는 이번 PR 범위에 포함되어 있지 않습니다. 해당 화면 연동에는 별도 서버 작업이 필요합니다.
