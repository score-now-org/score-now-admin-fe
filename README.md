# score-now-admin-fe
스코어나우 어드민페이지 프론트

## Tech Stack
- Vue 3
- Vite
- Pinia (State Management)
- Axios (HTTP Client)

## Project Structure
```text
src/
├── api/         # axios 설정 및 API 모듈
├── router/      # 라우팅 설정
├── stores/      # Pinia 상태관리
├── views/       # 페이지 (Login, Admin)
└── App.vue
```

## Getting Started
```
npm install
npm run dev
```




Access:
http://localhost:5173
